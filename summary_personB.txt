14. FINAL CONCLUSION
--------------------------------------------------
The clinical Cox model achieved an apparent C-index of 0.6606.
The radiomic Cox model achieved an apparent C-index of 0.6091.
The combined clinical-radiomic Cox model achieved the highest
apparent C-index of 0.7081.

The radiomic workflow reduced 107 initial features to 61 after
correlation filtering and selected three features using univariate
Cox screening.

The results suggest that the selected radiomic features may add
survival-related information beyond the clinical variables in this
exploratory cohort.

Because the radiomics cohort contains only 46 patients and the
feature-selection/model-fitting process used this cohort, the
C-index values should be treated as exploratory apparent performance,
not independently validated clinical performance.
